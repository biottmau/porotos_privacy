# Porotos — política de privacidad

Página pública (GitHub Pages) con la política de privacidad de la app **Porotos** (anotador de truco).
La fuente es `assets/store/listing/privacy-policy-es.md` del repo privado `biottux_porotos`.
Para actualizar: editar ese markdown, correr `python3 -I build.py` acá y subir el `index.html`.
No volver privado este repo: Pages se desactiva.
